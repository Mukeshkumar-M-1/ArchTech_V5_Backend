Summary
Claude Code's memory system is designed for an interactive CLI where an LLM agent reads and writes memories in real-time. ArchTech's memory system is designed for an API backend where extracted requirements are stored as structured JSON and queried via REST endpoints.

The key patterns shared between them are:

MEMORY.md index with truncation
Typed memories with frontmatter
Lazy loading (read index first)
Compaction thresholds (doc count instead of token count)
Per-project isolation
The key differences are:

Storage format (.md vs .json)
Query mechanism (LLM parses vs structured filter)
Extraction (forked agent vs synchronous pipeline)
Interface (CLI vs HTTP API)
