## Overview

Claude Code's GrowthBook system supports connecting to a custom GrowthBook server via environment variables for remote feature flag control.

- **When configured**: Connects to your GrowthBook instance, pulls, and caches feature values.
- **When not configured**: All feature reads directly return default values from the code, with zero network requests.

## Environment Variables

| Variable | Required | Description |
| ----------------------- | ---- | ------------------------------------------------- |
| `CLAUDE_GB_ADAPTER_URL` | Yes | GrowthBook API address, e.g., `https://gb.example.com/` |
| `CLAUDE_GB_ADAPTER_KEY` | Yes | GrowthBook SDK Client Key, e.g., `sdk-xxxxx` |

Enable adapter mode when both variables are set, otherwise completely skip GrowthBook.

## Usage

### Basic Usage

```bash
CLAUDE_GB_ADAPTER_URL=https://gb.example.com/ \
CLAUDE_GB_ADAPTER_KEY=sdk-abc123 \
bun run dev
```

### Without GrowthBook (Default Behavior)

```bash
bun run dev
# All getFeatureValue_CACHED_MAY_BE_STALE("xxx", defaultValue) calls directly return defaultValue
```

## GrowthBook Server Configuration

### Steps

1. **Deploy GrowthBook Server** (Self-hosted via Docker or Cloud version)
2. **Create Environment** (e.g., `production`)
3. **Create SDK Connection** to obtain the SDK Key (i.e., `CLAUDE_GB_ADAPTER_KEY`)
4. **Add Features as needed**, see the list below for keys and types

### Core Principles

- **Runs normally even without configuring any features**—every call in the code provides a default value.
- Only create features you want to control remotely; the rest will use code defaults.
- Once a feature is configured on GrowthBook, its value will override the default value in the code.

## Reading Priority Chain

The value of each feature is resolved in the following order, returning the first hit:

```
1. CLAUDE_INTERNAL_FC_OVERRIDES environment variable (JSON object override)
   ↓ No hit
2. growthBookOverrides configuration (~/.claude.json, ant build only)
   ↓ No hit
3. Memory cache (remoteEvalFeatureValues, pulled from server in current process)
   ↓ No hit
4. Disk cache (cachedGrowthBookFeatures in ~/.claude.json)
   ↓ No hit
5. defaultValue parameter in code
```

## Cache and Refresh Mechanism

| Mechanism | Description |
| -------------- | ----------------------------------------------------------------- |
| **Disk Cache** | `cachedGrowthBookFeatures` field in `~/.claude.json`, persistent across processes |
| **Periodic Refresh** | Automatically pulls latest values from server every 6 hours (`setInterval` + `unref`) |
| **Initialization Timeout** | 5-second timeout for first connection; falls back to disk cache or default values |
| **Auth Changes** | Automatically destroys and rebuilds client upon login/logout |

2. **`src/services/analytics/growthbook.ts`** — `isGrowthBookEnabled()` enables directly in adapter mode
3. **`src/services/analytics/growthbook.ts`** — Base URL prioritizes `CLAUDE_GB_ADAPTER_URL`

No modification needed for all 130+ calling files.
