## What is feature()?

Claude Code uses the `bun:bundle` module from the Bun bundler to provide compile-time feature gating:

```typescript
// Usage in source code (src/tools.ts, etc.)
import { feature } from 'bun:bundle'

const SleepTool = feature('PROACTIVE') || feature('KAIROS')
  ? require('@claude-code-best/builtin-tools/tools/SleepTool/SleepTool.js').SleepTool
  : null
```

In Anthropic's internal builds, `feature()` is evaluated during bundling—code returning `true` is retained, while code returning `false` is entirely removed by **Dead Code Elimination (DCE)**.

In our decompiled version, `feature` is imported from `bun:bundle` (declared in `src/types/internal-modules.d.ts`) and always returns `false` at runtime:

```typescript
// src/types/internal-modules.d.ts
declare module 'bun:bundle' {
  export function feature(name: string): boolean;
}
```

This means that code behind all 88+ feature flags **will never execute at runtime**, but the code itself is fully preserved for reading and analysis.

## Typical Patterns in Code

Feature flags are primarily used in three patterns in the codebase:

### Pattern 1: Conditional Tool Loading

```typescript
// src/tools.ts — The most common pattern
const MonitorTool = feature('MONITOR_TOOL')
  ? require('@claude-code-best/builtin-tools/tools/MonitorTool/MonitorTool.js').MonitorTool
  : null
```

When a flag is `false`, the `require()` call is removed by DCE, and the tool does not appear in the list of available tools.

### Pattern 2: Conditional Command Registration

```typescript
// src/commands.ts — Registering slash commands
if (feature('VOICE_MODE')) {
  commands.push({ name: 'voice', description: '...' })
}
```

### Pattern 3: Conditional API Feature Enablement

```typescript
// src/constants/betas.ts — Controls beta headers sent to the API
export const AFK_MODE_BETA_HEADER = feature('TRANSCRIPT_CLASSIFIER')
  ? 'afk-mode-2026-01-31'
  : ''
```

<Note>
Since `feature()` is evaluated at build-time, code removed by DCE does not increase the final bundle size. However, in our decompiled version, all this code is preserved—which is exactly why we can perform a full analysis.
</Note>

## Interesting Findings

- **KAIROS family** is the largest—6 related flags control everything from core functionality to push notifications.
- **ABLATION_BASELINE** is used for "scientific control experiments"—it disables advanced features like thinking, compaction, auto-memory, etc., to measure baseline performance of raw API calls.
- **BUDDY** is an AI mascot/virtual pet system—with a full implementation in the `src/buddy/` directory.
- **ULTRAPLAN** and **ULTRATHINK** hint at reasoning modes more advanced than the current extended thinking.
