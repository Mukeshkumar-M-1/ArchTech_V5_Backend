# Chrome Use — Quick Guide to Browser Automation

Let Claude Code directly control your Chrome browser and perform web operations using natural language.

## Quick Start (3 Minutes)

### Step 1: Install Chrome Extension

1.  Download the extension: https://github.com/hangwin/mcp-chrome/releases
2.  Extract the zip file.
3.  In Chrome, navigate to `chrome://extensions/`.
4.  Enable "Developer mode" in the top right corner.
5.  Click "Load unpacked" and select the extracted folder.

### Step 2: Start Claude Code

```bash
bun run dev
# OR use the installed ccb
ccb
```

### Step 3: Enable Chrome MCP

1.  In the REPL, type `/mcp` to open the MCP panel.
2.  Locate `mcp-chrome` and press Space to enable it.
3.  Press Enter to confirm.
