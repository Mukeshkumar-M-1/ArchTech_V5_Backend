# Software Requirements

## Summary

This category covers the development of a micro-controller-based software application featuring a Graphical User Interface (GUI). The primary purpose is to enable users to configure and test on-board external Integrated Circuits (ICs) via USB connectivity, specifically managing SPI and I2C peripherals.
