# Application Requirements

## Summary

This sub-category defines the development of a USB-based graphical user interface (GUI) application for the micro-controller, enabling users to configure on-board external ICs via SPI and I2C protocols and facilitating test application updates.

## Requirements

| ID | Priority | Description Preview | Link |
|----|----------|---------------------|------|
| SOF-0014 | High | A micro-controller USB based GUI application shall be developed. Using the GUI, the micro-controller peripherals such as SPI and I2C which are used for on-board external ICs shall be configured; Testing Plan: The test application shall be updated from the USB based GUI of DP-VPX-6005 | [SOF-0014.md](../requirements/SOF-0014.md) |
