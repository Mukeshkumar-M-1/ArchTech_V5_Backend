# FPGA Requirements

## Summary

This sub-category defines the hardware specifications for the DP-XMC-5049 module, mandating the use of Xilinx Kintex Ultrascale+ FPGAs (specifically the XCKU035 device). It details the required interface support for video standards (STANAG3350, RGB, VGA, DVI, ARINC818), memory configurations (DDR4, SPI NOR), and physical connectivity via XMC PCIe interfaces.
