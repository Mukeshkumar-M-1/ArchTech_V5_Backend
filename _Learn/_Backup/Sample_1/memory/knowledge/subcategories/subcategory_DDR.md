# DDR Requirements

## Summary

This sub-category defines the implementation of a 64-bit DDR4 SDRAM controller IP core within the FPGA IO bank, utilizing a reference clock from a clock generator to manage high-speed external memory access.

## Requirements

| ID | Priority | Description Preview | Link |
|----|----------|---------------------|------|
