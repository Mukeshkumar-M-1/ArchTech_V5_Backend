# I2C Requirements

## Summary

This sub-category defines the requirement for the FPGA to communicate with a temperature sensor using the I2C protocol on the IO bank for system hardware monitoring.

## Requirements

| ID | Priority | Description Preview | Link |
|----|----------|---------------------|------|
