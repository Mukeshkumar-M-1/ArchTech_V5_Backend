# HAR-0036 | Supported OS and SBC-Based PCIe Enumeration

## Requirement

DP-XMC-5049-HRS-0019: Supported OS: Linux / Windows (SBC external module for PCIe enumeration)

## Explanation

This requirement defines the software environment compatibility and the architectural mechanism for hardware initialization. The XMC module is designed to operate within standard computing environments supporting either the Linux or Windows operating systems.

A key architectural constraint is that the module does not handle PCIe enumeration internally. Instead, it relies on an external Single Board Computer (SBC) module. This external SBC is responsible for detecting the hardware, managing the PCIe bus enumeration, and establishing the connection. This design choice likely simplifies the FPGA logic on the XMC module by offloading complex host-interface management tasks to a dedicated, general-purpose computing unit.

**Key Components:**
*   **Operating Systems:** Linux, Windows
*   **Hardware Interface:** External Single Board Computer (SBC)
*   **Function:** PCIe Enumeration and Host Detection
