# HAR-0054 | USB 2.0 Interface Support

## Requirement

Requirement ID: DP-XMC-5049-HRS-0016; Requirement: USB2.0; Testing Plan: NA

## Explanation

The system hardware must provide connectivity support for the Universal Serial Bus (USB) 2.0 standard. This implies the presence of physical ports and associated controller logic capable of handling USB 2.0 data rates (High-Speed up to 480 Mbps) and backward compatibility with USB 1.1 devices.
