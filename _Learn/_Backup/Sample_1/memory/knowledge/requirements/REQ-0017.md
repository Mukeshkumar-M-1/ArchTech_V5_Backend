# REQ-0017 | PCIe XMC Primary Connector to FPGA MGT Bank Link

## Requirement

DP-XMC-5049-HRS-0014 PCIe: 1x x8 PCIe Gen 3 link between XMC Primary Connector and MGT bank of FPGA.

## Explanation

This requirement specifies the physical and logical interface configuration for the high-speed data path between the XMC (PCIe Mezzanine Card) Primary Connector and the Field Programmable Gate Array (FPGA). Specifically, it mandates a single PCIe Gen 3 link operating in x8 lane width. This connection utilizes the FPGA's Multi-Gigabit Transceiver (MGT) bank, which is the dedicated hardware block responsible for handling high-speed serial I/O operations required by PCIe standards. The purpose of this link is to ensure high-bandwidth data transfer capabilities between the mezzanine card interface and the core processing logic of the FPGA.
