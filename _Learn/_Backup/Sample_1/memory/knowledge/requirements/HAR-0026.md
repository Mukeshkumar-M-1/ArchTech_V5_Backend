# HAR-0026 | Micro-controller Specification (ATSAMD51G19A)

## Requirement

DP-XMC-5049-HRS-003 Micro-controller • Family: SAM D5x/E5x • Device: ATSAMD51G19A • Core: 32-bit Arm® Cortex®-M4F MCUs • Memory: 512KB in-system self-programmable Flash • RAM: 192KB SRAM

## Explanation

This requirement defines the specific microcontroller unit (MCU) selected for the DP-XMC-5049 hardware platform. The selected component is the Microchip ATSAMD51G19A, which belongs to the SAM D5x/E5x family. It is built around a 32-bit Arm® Cortex®-M4F core, providing floating-point unit (FPU) capabilities suitable for signal processing and control applications.

Key specifications include:
- **Core Architecture**: 32-bit Arm® Cortex®-M4F with DSP instructions and FPU.
- **Program Memory**: 512KB of in-system self-programmable Flash, allowing for flexible firmware updates and storage.
- **Data Memory**: 192KB of Static RAM (SRAM) for runtime data and stack operations.

This MCU serves as the primary control processor for the module, handling system initialization, peripheral management, and potentially communication protocols with the host PCIe interface.
