# REQ-0051 | DP/DP++ Input via XMC Secondary Connector

## Requirement

DP-XMC-5049-HRS-0012 DP/DP++ Input: One DP/DP++ Input from XMC Secondary Connector.

## Explanation

The system is required to provide a single DisplayPort (DP) or DisplayPort++ input interface. This input must be physically routed to and accessible via the XMC Secondary Connector. This specification ensures that video or data streams compliant with the DisplayPort standard can be ingested by the system through the designated secondary expansion slot interface.

**Key Components:**
*   **DP/DP++ Input:** The logical interface for receiving DisplayPort signals.
*   **XMC Secondary Connector:** The physical hardware interface on the XMC module where this input is terminated.

**Purpose:**
To enable video or data input capabilities via the DisplayPort standard, specifically leveraging the XMC Secondary Connector for connectivity.
