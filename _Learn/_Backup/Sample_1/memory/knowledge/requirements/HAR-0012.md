# HAR-0012 | Kintex Ultrascale FPGA Specification (XCKU035)

## Requirement

DP-XMC-5049-HRS-002 FPGA • Family: Kintex Ultrascale • Device: XCKU035-2FBVA676I • Logic cells: 444,343 • Maximum HP I/Os: 416 • Maximum HR I/Os: 104 • Block RAM Blocks: 540 • Distributed RAM: 5.9 Mb (Max.) • Block RAM: 19.0 Mb • CMTs: 10 • DSP 48e1 Slices: 1,700 • PCIe Gen3 x8: 2 • GTH 16.3 Gb/s Transceivers: 16

## Explanation

This requirement defines the specific hardware component selected for the FPGA slot on the DP-XMC-5049 module. It mandates the use of a Xilinx Kintex UltraScale device, specifically the **XCKU035-2FBVA676I** variant. The specification details the internal resource allocation, which is critical for determining the computational capacity, memory availability, and interface bandwidth of the module.

Key aspects include:
- **Logic Capacity**: The device provides 444,343 logic cells, suitable for complex digital signal processing and control logic.
- **Memory Resources**: It includes 540 Block RAM blocks (totaling 19.0 Mb) and 5.9 Mb of Distributed RAM, essential for data buffering and storage within the FPGA fabric.
- **High-Speed Interfaces**: The FPGA supports two PCIe Gen3 x8 interfaces and 16 GTH transceivers capable of 16.3 Gb/s, enabling high-bandwidth communication with the host system and other peripherals.
- **Processing Units**: With 1,700 DSP 48e1 slices and 10 Clock Management Tiles (CMTs), the device is well-suited for high-performance arithmetic operations and precise clock distribution.
