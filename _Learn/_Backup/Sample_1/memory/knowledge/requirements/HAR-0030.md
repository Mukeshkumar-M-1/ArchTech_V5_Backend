# HAR-0030 | Power Supply Current Consumption Specifications

## Requirement

DP-XMC-5049-HRS-005 Current • 5V @ 2.99 A (TYP) • 3V @ 3.18 A (TYP) • 3.3V-AUX @ 0.002 A (TYP)

## Explanation

This requirement defines the typical current consumption for the various power supply rails of the DP-XMC-5049 module. It specifies the expected electrical load for the 5V, 3V, and 3.3V-AUX rails under typical operating conditions. These values are critical for power budgeting, thermal management, and ensuring the host system can provide sufficient current without voltage droop.

**Key Parameters:**
- **5V Rail:** 2.99 A (Typical)
- **3V Rail:** 3.18 A (Typical)
- **3.3V-AUX Rail:** 0.002 A (Typical)
