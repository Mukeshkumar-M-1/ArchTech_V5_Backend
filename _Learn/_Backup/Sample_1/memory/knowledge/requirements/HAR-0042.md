# HAR-0042 | DDR4 Full Memory Test

## Requirement

Requirement ID: DP-XMC-5049-HRS-007; Requirement: DDR4 full memory test shall be performed; Testing Plan: Refer DP- VPX-5792 test application

## Explanation

This requirement mandates the execution of a comprehensive diagnostic routine for the DDR4 memory subsystem. The goal is to verify the integrity, stability, and functionality of the entire memory capacity installed on the module.

**Key Aspects:**
- **Scope:** The test must cover the *full* memory range, not just a subset or specific addresses.
- **Standard:** It implies a standard memory stress test or pattern write/read verification to detect bit errors, timing issues, or hardware defects.
- **Reference:** The specific methodology, patterns, and pass/fail criteria are defined in the external document **DP-VPX-5792** (Test Application). This requirement acts as a pointer to that detailed testing procedure.

**Components Involved:**
- DDR4 Memory Modules
- Memory Controller (FPGA/ASIC)
- Test Application Framework (DP-VPX-5792)
