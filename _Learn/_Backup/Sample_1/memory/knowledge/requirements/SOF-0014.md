# SOF-0014 | Micro-controller USB-based GUI for Peripheral Configuration

## Requirement

Requirement ID: DP-XMC-5049-HRS-003; Requirement: A micro-controller USB based GUI application shall be developed. Using the GUI, the micro-controller peripherals such as SPI and I2C which are used for on-board external ICs shall be configured; Testing Plan: The test application shall be updated from the USB based GUI of DP-VPX-6005

## Explanation

This requirement mandates the development of a dedicated software tool to facilitate hardware configuration and testing. The core deliverable is a Graphical User Interface (GUI) application that communicates with the system via a USB connection to a micro-controller.

**Key Functionalities:**
1.  **Peripheral Configuration:** The GUI must provide controls to configure specific micro-controller peripherals, specifically **SPI** and **I2C** buses.
2.  **External IC Management:** These peripherals are used to interface with on-board external Integrated Circuits (ICs). The GUI allows users to set parameters for these external components.
3.  **Testing Integration:** The requirement explicitly links this GUI to the testing process for the **DP-VPX-6005** module. The "test application" (likely referring to the firmware or the configuration state of the device under test) must be updatable or verifiable through this USB-based GUI.

**Clarification on Architecture:**
While the text mentions a "micro-controller USB based GUI," it implies a host-side application (running on a PC) that connects to the target hardware (containing the micro-controller) via USB. The GUI serves as the human-machine interface for the embedded system's configuration.
