# HAR-0020 | STANAG 3350 / VGA Video Output via FPGA

## Requirement

Requirement ID: DP-XMC-5049-HRS-0013; Requirement: STANAG 3350 / VGA Video; Testing Plan: DisplayPort Video input data shall be received on FPGA. Same video data received on FPGA shall be sent out via Video encoder IC which shall be interfaced to standard VGA / PAL display. Software: Refer DP- VPX-5792 test application

## Explanation

This requirement defines the video signal processing and output pathway for the XMC module. The system must accept video input via DisplayPort, process it within the FPGA, and then output the identical video stream through a dedicated Video Encoder IC. The final output must be compatible with standard VGA or PAL displays, adhering to the STANAG 3350 standard. The validation of this functionality is supported by the DP-VPX-5792 test application.

**Key Components Involved:**
*   **FPGA:** Acts as the central processing unit for receiving DisplayPort data and routing it to the encoder.
*   **Video Encoder IC:** Converts the digital video signal from the FPGA into an analog format suitable for VGA/PAL monitors.
*   **Display:** Standard VGA or PAL monitor serving as the output endpoint.
*   **Test Application:** DP-VPX-5792, used for verifying the end-to-end video path.

**Technical Context:**
The requirement implies a data path integrity check: the video data received at the input (DisplayPort) must be identical to the data transmitted to the output (VGA/PAL). This ensures no corruption or significant latency is introduced during FPGA processing and encoding.
