# REQ-0011 | VITA 42 Compliant XMC Module with Kintex Ultrascale FPGA

## Requirement

2.1 Features VITA 42 Compliant XMC Module; Kintex Ultrascale series FPGA with two 4GB DDR4 SDRAM controller; x8 PCIe Gen 3 links on XMC Primary Connector; Dual mode displayport video input; 2x Single link DVI outputs on XMC Secondary Connector (FG configurable); 1x Single link DVI output on DVI Connector at Front panel (FG configurable); 3x ARINC 818 Transmitter(Tx & Rx) on XMC Secondary Connector (FG configurable); RGBHV / VGA / STANAG 3350 Output using Encoder on XMC Secondary Connector (FG configurable)

## Explanation

This requirement defines the core hardware specifications and feature set for a VITA 42 compliant XMC (eXtensions for Mechanical Control) module. The central processing element is a Xilinx Kintex Ultrascale series FPGA, supported by significant memory resources (two 4GB DDR4 SDRAM controllers).

The module provides high-speed data connectivity via an x8 PCIe Gen 3 link on the primary connector. It offers extensive video and data I/O capabilities, primarily through the XMC Secondary Connector and a front-panel DVI connector. Key features include:
- **Video Input:** Dual mode DisplayPort.
- **Video Outputs:** Multiple configurable DVI outputs (2x on XMC Secondary, 1x on Front Panel).
- **Data/Avionics:** 3x ARINC 818 Transceivers (Tx & Rx).
- **Signal Encoding:** Support for RGBHV, VGA, and STANAG 3350 outputs via an encoder on the XMC Secondary Connector.

Many of the output configurations are Field-Programmable (FG configurable), allowing for flexible deployment based on specific mission or system requirements.
