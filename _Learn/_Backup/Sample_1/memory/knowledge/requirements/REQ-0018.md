# REQ-0018 | FPGA I2C Temperature Sensor Read

## Requirement

The FPGA shall read the temperature sensor via the I2C interface on the IO bank.

## Explanation

This requirement specifies the mechanism by which the Field Programmable Gate Array (FPGA) acquires thermal data from a dedicated temperature sensor. The communication must occur over the Inter-Integrated Circuit (I2C) bus, which is mapped to a specific Input/Output (IO) bank on the FPGA device.

**Key Components:**
*   **FPGA:** The primary controller initiating the read operation.
*   **Temperature Sensor:** The peripheral device providing the thermal data.
*   **I2C Interface:** The serial communication protocol used for data transfer.
*   **IO Bank:** The physical group of pins on the FPGA package that supports the I2C voltage levels and signaling.

**Purpose:**
To enable real-time monitoring of system hardware temperature, ensuring thermal safety and operational stability.
