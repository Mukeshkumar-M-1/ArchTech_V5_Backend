# HAR-0044 | DP/DP++ Video Input Routing Verification

## Requirement

Requirement ID: DP-XMC-5049-HRS-0012; Requirement: DP/DP++ Video Input; Testing Plan: DisplayPort source shall be used to send video data and same video shall be sent out via each DVI channel to a DVI monitor; Software: Refer DP- VPX-5792 test application

## Explanation

This requirement defines the functional verification for the video input interface of the XMC module. The core objective is to ensure that video signals received via a DisplayPort (DP or DP++) source are correctly routed and replicated to all available DVI output channels.

**Key Verification Steps:**
1.  **Input Source:** Connect a standard DisplayPort source to the module's DP input.
2.  **Signal Routing:** Verify that the incoming video stream is accessible internally.
3.  **Output Verification:** Connect DVI monitors to each DVI channel on the module.
4.  **Consistency Check:** Confirm that the exact same video content displayed on the DP source is simultaneously and correctly rendered on every connected DVI monitor.

**Software Support:**
The verification process relies on the specific test application identified as **DP-VPX-5792**. This software likely handles the configuration of the DP input and the monitoring of DVI outputs to automate or facilitate the consistency check.

**Components Involved:**
-   DisplayPort (DP/DP++) Input Interface
-   DVI Output Channels
-   DVI Monitors (Test Equipment)
-   DP-VPX-5792 Test Application
