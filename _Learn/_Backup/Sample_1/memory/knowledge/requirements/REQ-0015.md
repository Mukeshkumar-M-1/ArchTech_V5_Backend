# REQ-0015 | PCIe Interface Configuration and Clocking

## Requirement

PCIe interface: x8 PCIe interface on FPGA MGT bank; Reference clock from clock generator to FPGA MGT bank shall be used for PCIe.

## Explanation

This requirement specifies the physical layer configuration for the Peripheral Component Interconnect Express (PCIe) interface on the FPGA. It mandates two critical hardware connections:

1.  **Lane Configuration**: The PCIe interface must utilize an x8 lane configuration. This is implemented on the FPGA's Multi-Gigabit Transceiver (MGT) bank, which provides the high-speed serial transceivers necessary for PCIe communication.
2.  **Clocking Scheme**: A dedicated reference clock must be sourced from an external clock generator and routed directly to the FPGA MGT bank. This ensures that the PCIe transceivers have a stable, low-jitter reference signal required for proper link training and data integrity.

The combination of an x8 lane width and a dedicated reference clock is essential for achieving high bandwidth and reliable synchronization in high-speed data transfer applications.
