# HAR-0007 | XMC PCIe and ARINC 818 Interface Requirements

## Requirement

The module shall support high speed communication interface such as PCIe on XMC primary connector for video raw data reception / transmission. The XMC Primary connector interfaces x8 PCIe lines from the carrier module. Module shall optionally support 3x ARINC 818 Transmitter(Tx) and 3x ARINC 818 Receiver(Rx) interfaces from the secondary XMC connector to the MGT bank of FPGA.

## Explanation

This requirement defines the physical and logical interface specifications for an XMC (VITA 23) module designed for video data processing. It mandates a high-bandwidth primary interface using PCIe over the XMC primary connector, specifically utilizing x8 lanes for raw video data throughput. Additionally, it specifies optional avionics-grade communication capabilities via ARINC 818 on the secondary connector, routing these signals directly to the FPGA's Multi-Gigabit Transceiver (MGT) bank.

**Key Components:**
*   **XMC Primary Connector:** Handles high-speed PCIe data.
*   **Carrier Module:** Provides the x8 PCIe lines.
*   **XMC Secondary Connector:** Handles optional ARINC 818 interfaces.
*   **FPGA MGT Bank:** Receives ARINC 818 signals from the secondary connector.
*   **ARINC 818 Interfaces:** 3 Transmitters (Tx) and 3 Receivers (Rx).

**Technical Parameters:**
*   **PCIe Lanes:** x8
*   **ARINC 818 Tx:** 3 channels (Optional)
*   **ARINC 818 Rx:** 3 channels (Optional)

**Purpose:**
To ensure the module can handle high-bandwidth raw video data transmission/reception via PCIe while providing flexibility for specialized avionics communication through ARINC 818, leveraging the FPGA's high-speed transceivers.
