# HAR-0013 | XMC Primary Connector Interface Requirements

## Requirement

DP-XMC-5049-HRS-0017: XMC Primary Connector requirements: 5V DC supply; 3.3V DC supply; 3.3V-AUX DC supply; Module JTAG Interface; PCIe REFCLK; 1x x8 PCIe Gen 3 link from FPGA MGT bank.

## Explanation

This requirement defines the mandatory electrical and logical interfaces provided by the XMC Primary Connector for the module. It ensures that the host system or backplane provides the necessary infrastructure for power, configuration, clocking, and high-speed data transmission.

**Key Components:**
*   **Power Supplies:** Three distinct DC voltage rails are required to power different sections of the module (main logic, auxiliary circuits, and potentially I/O).
*   **Debugging:** The JTAG interface is essential for initial configuration, firmware updates, and hardware debugging.
*   **Clocking:** A dedicated PCIe Reference Clock (REFCLK) is required to synchronize the high-speed serial links.
*   **Data Link:** A high-bandwidth PCIe Gen 3 link with an x8 lane width is required for data throughput, originating from the FPGA's Multi-Gigabit Transceiver (MGT) bank.

**Purpose:**
To guarantee that the module has access to stable power, precise timing, debug capabilities, and sufficient bandwidth for its intended high-speed operations via the primary XMC connector.
