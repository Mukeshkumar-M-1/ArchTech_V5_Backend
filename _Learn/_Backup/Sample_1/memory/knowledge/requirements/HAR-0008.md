# HAR-0008 | Video Output Interface Specifications

## Requirement

The module shall support 1x single link DVI output via DVI equalizer interfaced from either FPGA or DP to DVI splitter to XMC secondary connector. The module shall additionally support 1x single link DVI output from DP to DVI splitter interfaced to the DVI Connector on the Front panel via DVI equalizer. The module shall also support 1x DVI output from DP to DVI splitter interfaced to the XMC secondary connector on the Front panel via DVI equalizer. The module shall support RGBHV / VGA / STANAG 3350 analog video standard output on XMC Secondary connector using Video encoder with recommended front end.

## Explanation

This requirement defines the video output capabilities of the XMC module, specifying both digital DVI and analog video interfaces. The module must provide flexible routing options for video signals, allowing outputs to be directed to either the XMC backplane connector or the front panel.

**Key Functional Areas:**

1.  **Digital DVI Outputs:**
    *   The system supports **three distinct DVI output paths**, all utilizing DVI equalizers to ensure signal integrity.
    *   **Path 1:** Source (FPGA or DP) $\rightarrow$ DP to DVI Splitter $\rightarrow$ DVI Equalizer $\rightarrow$ XMC Secondary Connector.
    *   **Path 2:** Source (DP) $\rightarrow$ DP to DVI Splitter $\rightarrow$ DVI Equalizer $\rightarrow$ Front Panel DVI Connector.
    *   **Path 3:** Source (DP) $\rightarrow$ DP to DVI Splitter $\rightarrow$ DVI Equalizer $\rightarrow$ XMC Secondary Connector (Front Panel accessible).
    *   *Note:* The requirement specifies "single link" DVI for the first two outputs. The third output is described generally as "1x DVI output" but implies similar single-link constraints based on the context of the other outputs.

2.  **Analog Video Outputs:**
    *   The module must support analog video standards on the **XMC Secondary Connector**.
    *   Supported standards include **RGBHV**, **VGA**, and **STANAG 3350**.
    *   Implementation requires a **Video Encoder** and a recommended front-end circuit.

**Components Involved:**
*   **Signal Processing:** DVI Equalizers, DP to DVI Splitters, Video Encoder.
*   **Connectors:** XMC Secondary Connector, Front Panel DVI Connector.
*   **Sources:** FPGA, DisplayPort (DP).

**Purpose:**
To provide versatile video connectivity for military and industrial applications, supporting both standard digital displays (DVI) and legacy or specialized analog displays (VGA/STANAG) via flexible routing between the backplane and front panel.
