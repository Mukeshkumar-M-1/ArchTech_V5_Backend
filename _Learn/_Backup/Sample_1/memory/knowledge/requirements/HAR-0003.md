# HAR-0003 | DisplayPort Video Input and TMDS Output Splitter

## Requirement

The module shall support DisplayPort video input from secondary XMC Connector which are electrically translated to the 3 no.s of TMDS level DP++/DVI outputs using DP to DP++/DVI splitter. The DP++ Video splitter shall be interfaced with a 2MB SPI NOR Flash.

## Explanation

This requirement defines the video signal distribution architecture for the module. It mandates that the system accepts a single DisplayPort (DP) video stream via the secondary XMC connector. This input must be electrically converted and distributed to three distinct outputs. These outputs are specified as TMDS-level DP++ or DVI compatible signals.

The core component facilitating this conversion is a DP to DP++/DVI splitter. To ensure proper configuration and operation of this splitter, the design must include an interface to a 2MB SPI NOR Flash memory chip. This memory is likely used to store EDID data, configuration registers, or firmware required by the splitter IC to manage the signal translation and output formatting.

**Key Technical Aspects:**
- **Input:** Single DisplayPort signal from Secondary XMC Connector.
- **Conversion:** Electrical translation to TMDS levels.
- **Output:** Three (3) independent DP++/DVI outputs.
- **Control/Config:** 2MB SPI NOR Flash connected to the splitter.
