# REQ-0031 | Kintex Ultrascale XCKU035 FPGA Selection

## Requirement

The Kintex Ultrascale XCKU035 series FPGA shall be used in the module with sufficient IO count as per design requirement.

## Explanation

This requirement mandates the specific selection of the Xilinx Kintex UltraScale FPGA from the XCKU035 family for the hardware module. The primary constraint is that the chosen device variant within this series must possess an Input/Output (IO) pin count that satisfies the electrical and logical interface requirements of the system design. This ensures that the FPGA can handle all necessary external connections without requiring additional bridging logic or external I/O expanders, which could impact performance, latency, or board space.

**Key Components:**
- **Device Family:** Xilinx Kintex UltraScale
- **Specific Series:** XCKU035

**Design Constraints:**
- **IO Capacity:** The selected FPGA variant must have a sufficient number of General Purpose Input/Output (GPIO) pins and high-speed transceivers to meet the system's interface specifications.
