# HAR-0025 | ARINC 818 Video Data Transfer Testing

## Requirement

Requirement ID: DP-XMC-5049-HRS-0011; Requirement: ARINC 818; Testing Plan: ARINC 818 standard Video data transfer test shall be done using external ARINC 818 to DVI conversion module; Software: Refer DP- VPX-5792 test application

## Explanation

This requirement mandates the validation of video data transmission capabilities over the ARINC 818 interface. The testing procedure involves utilizing an external hardware module to convert the ARINC 818 signal to DVI format, allowing for visual verification or standard DVI-based analysis of the video stream. The software component for this test is defined by the DP-VPX-5792 test application, which likely controls the data generation or reception logic on the VPX side.

**Key Components:**
*   **Interface:** ARINC 818 (Aerospace standard for high-speed serial video data).
*   **Test Hardware:** External ARINC 818 to DVI Conversion Module (External test fixture).
*   **Software:** DP-VPX-5792 Test Application.

**Test Objective:**
Verify that the system can successfully transfer video data according to the ARINC 818 standard specifications.
