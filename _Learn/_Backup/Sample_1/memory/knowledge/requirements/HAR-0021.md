# HAR-0021 | PCIe Enumeration and SBC Root Complex Testing

## Requirement

Requirement ID: DP-XMC-5049-HRS-0014; Requirement: PCIe; Testing Plan: Standard PCIe enumeration test shall be performed with any standard SBC PCIe root complex; Software: Refer DP-VPX-0750 or DP-VPX-0930 test application

## Explanation

This requirement mandates the verification of the PCIe interface functionality through a standard enumeration process. The testing must be conducted using a standard Single Board Computer (SBC) acting as the PCIe root complex. The specific software procedures for this validation are defined in the test applications referenced as DP-VPX-0750 or DP-VPX-0930. This ensures that the module correctly initializes and communicates with standard host systems.

**Key Components:**
*   **Interface:** PCIe
*   **Test Environment:** Standard SBC with PCIe root complex
*   **Test Procedure:** Standard PCIe enumeration
*   **Reference Software:** DP-VPX-0750 or DP-VPX-0930
