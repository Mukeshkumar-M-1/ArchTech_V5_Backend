# HAR-0035 | SDRAM Memory Specification

## Requirement

DP-XMC-5049-HRS-007 SDRAM • 64-bit 4GB DDR4

## Explanation

This requirement specifies the primary volatile memory configuration for the DP-XMC-5049 hardware module. The system utilizes a 4GB capacity DDR4 SDRAM module with a 64-bit data bus width. This configuration is designed to support high-speed data storage and processing tasks, ensuring sufficient bandwidth and capacity for the module's operational requirements.

**Key Components:**
- **Type:** SDRAM (Synchronous Dynamic Random-Access Memory)
- **Generation:** DDR4 (Double Data Rate 4)

**Technical Parameters:**
- **Data Width:** 64-bit
- **Total Capacity:** 4GB
