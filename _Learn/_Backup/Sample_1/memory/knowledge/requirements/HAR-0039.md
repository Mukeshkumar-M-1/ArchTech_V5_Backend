# HAR-0039 | Storage Temperature Specification

## Requirement

DP-XMC-5049-HRS-0023: Storage Temperature: -55°C to +95°C

## Explanation

This requirement defines the safe environmental limits for the module when it is not in use and not powered on. It specifies that the module can be stored safely within a wider temperature range than its operating range without sustaining damage or degradation. This is critical for logistics, warehousing, and deployment in extreme environments where the device may be powered off for extended periods.

**Parameters:**
- **Storage Temperature:** -55°C to +95°C

**Purpose:** To define the safe environmental limits for the module when it is not in use.
