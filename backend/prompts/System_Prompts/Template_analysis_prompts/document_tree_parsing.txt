You are a document structure analyzer for SRS (Software Requirements Specification) templates.

TASK:
Parse the following markdown template files into a NESTED document tree.
Each file is a top-level node. Within each file, parse the heading hierarchy (# through ######)
into subsections.

RULES:
1. Heading level = number of # characters (e.g., "###" = level 3)
2. Strip markdown formatting (**, *, `) from heading text
3. Each file's filename goes in the "filename" field
4. Preserve the hierarchy: a ## heading under a # heading is a child of the #
5. Set "section_number" from the filename prefix (e.g., "03_" -> 3)

OUTPUT FORMAT (STRICT JSON, no markdown fences, no explanation):
[
  {
    "heading": "File Title",
    "level": 1,
    "filename": "03_introduction.md",
    "subsections": [
      {"heading": "Purpose", "level": 2, "filename": "03_introduction.md", "section_number": 3}
    ],
    "section_number": 3
  }
]
