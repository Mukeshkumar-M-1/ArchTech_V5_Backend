# Ambient Light Sensor Test Specification

| Test cases | Description |
|---|---|
| **Ambient Light Sensor Test** | Reads the ambient light sensor value from ADC for 3 times and finds the median of the three readings. Use the median value to compute light. Checks whether the read value is within the valid range of Ambient light. If the read value is within the valid range, test is PASS, otherwise FAIL. **Note:** Ambient light sensor validation range shall be configurable. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
