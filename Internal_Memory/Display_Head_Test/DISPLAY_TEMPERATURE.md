# Display Head LCD Temperature Test Specification

| Test cases | Description |
|---|---|
| **Display Head LCD Temperature Test** | Reads the Display Head LCD / LED temperature value 3 times and finds the median of the three readings. Checks whether the median value is within the valid range. If the read value is within the valid range, test is PASS, otherwise FAIL. **Note:** Display Head LCD / LED temperature validation range shall be configurable. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
