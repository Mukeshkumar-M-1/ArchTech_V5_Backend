# Display Backlight Test Specification

| Test cases | Description |
|---|---|
| **Display Backlight Test** | Reads the Day / NVIS mode — display Back light current and voltage value for 3 times. Calculates the median of the samples. Compares the display Back light current and voltage value with the tolerance value. If the read value is within the tolerance, the test is considered as PASS, otherwise FAIL. **Note:** Display backlight validation range shall be configurable. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
