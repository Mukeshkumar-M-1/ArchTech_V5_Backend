# Rotary Encoder Position Test Specification

| Test cases | Description |
|---|---|
| **Rotary Encoder Position Test** | Display Head shall read Rotary encoder position value and send the Optical encoder position value to Host through RS422. Rotary encoder shall be rotated 1 to N steps in clockwise direction and encoder position shall be monitored. Rotary encoder shall be rotated 1 to N steps in anti-clockwise direction and encoder position shall be monitored. If the rotated steps and read position values match, the test is considered as PASS. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
