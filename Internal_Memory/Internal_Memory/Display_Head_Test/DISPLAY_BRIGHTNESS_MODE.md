# Display Brightness Mode Switching Test Specification

| Test cases | Description |
|---|---|
| **Display Brightness Mode Switching Test** | LCD Back Light Driver shall check the health of current brightness mode (Day/NVIS) of display Back light. If the current brightness mode fails, it shall switch over to the other brightness mode automatically. Set the brightness mode as Day. Upload invalid data for Day and valid data for NVIS — NVIS mode shall be set. Set the brightness mode as NVIS. Upload invalid data for NVIS and valid data for Day — Day mode shall be set. |
