# Bezel Key Illumination Control Test Specification

| Test cases | Description |
|---|---|
| **Bezel Key Brightness through RS232/RS422** | Bezel key backlight shall be changed to 25, 50, 75 & 100 and the variation in Bezel key brightness shall be observed. The expected result shall be Bezel keys (1 to n) illumination increase in order from 25%, 50%, 75% and 100% with uniformity. The same brightness shall be read back using software panel. |
| **Bezel Key Brightness through Analog Input** | Analog input shall be varied from 0 to 28V and variation in Bezel key brightness shall be observed. The expected result shall be Bezel keys (1 to n) illumination increase by increasing the voltage and decrease by decreasing the voltage. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
