# Altivec Test Specification

| Test cases | Description |
|---|---|
| **Vector Integer Operations** | Qualifies the Altivec engine by performing vector integer operations. Predefined vector operands shall be processed using supported integer instructions and results compared against expected values. If all results match, test is PASS, otherwise FAIL. |
| **Vector Floating Point Operations** | Qualifies the Altivec engine by performing vector floating point operations. Predefined vector operands shall be processed using supported floating point instructions and results compared against expected values within acceptable tolerance. If all results match, test is PASS, otherwise FAIL. |
| **Vector Shift Operations** | Qualifies the Altivec engine by performing vector shift operations. Predefined vector data shall be shifted by specified bit positions and results compared against expected values. If all results match, test is PASS, otherwise FAIL. |
| **Vector Bit-wise Operations** | Qualifies the Altivec engine by performing vector bit-wise operations (AND, OR, XOR, NOT). Predefined vector operands shall be processed and results compared against expected values. If all results match, test is PASS, otherwise FAIL. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
