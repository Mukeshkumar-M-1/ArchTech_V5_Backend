# Timer Test Specification

| Test cases | Description |
|---|---|
| **Timer Test** | Carried out by enabling and then disabling a timer interrupt after a defined time duration (e.g., 60 seconds). If the interrupt counter value after disabling and the expected count value are the same, test is PASS, otherwise FAIL. Requires 2 timers — a reference timer and timer under test. Timer under test may be configured for generating interrupt periodically at 'x' msec and a software counter may be maintained to count the number of interrupts generated. Another reference timer may be initialized to 'nx' msec where 'n' is the number of interrupts generated by the first timer. As part of reference timer ISR, the software counter value may be checked for 'n'. **Note:** The test result with a tolerance of +/-1 count in addition to the expected interrupt count will be considered as PASS. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
