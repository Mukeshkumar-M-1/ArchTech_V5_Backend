# ARINC 717 Test Specification

| Test cases | Description |
|---|---|
| **ARINC 717 Test** | Performed between 2 ARINC 717 channels. Data to be transmitted shall be framed as per protocol (4 sub-frames with 38 to 1K words of data per sub-frame). Both Tx and Rx channels shall be configured and data shall be transmitted from Tx to Rx. If both transmitted and received data are the same, test is PASS, otherwise FAIL. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
