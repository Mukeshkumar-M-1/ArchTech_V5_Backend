# 1553B Test Specification

| Test cases | Description |
|---|---|
| **Self Test** | If the chip has provision to conduct self test and read the result, then chip self test shall be carried out. Otherwise the following test cases shall be carried out: 1. Data Bus Test, 2. Address Bus Test, 3. Memory Test, 4. Interrupt Test (if available in driver). |
| **Loop Back Test** | Carried out if there are a minimum of 3 channels. 1 channel configured as BC, 1 channel as RT, and another as MT. Predefined data shall be transmitted to the configured RT channels of all sub-addresses (1-30) and the received data shall be sent back to BC from the configured RT channels of all sub-addresses. Both transmissions shall be monitored by the configured MT channels. If all transmitted and equivalent received data are the same, test is PASS, otherwise FAIL. Data captured by MT shall be verified for BC/RT transmission and RT/BC reception. These can be repeated by changing the channel nodes between BC, RT and MT. One RT address with all sub-addresses (30*668) microseconds and all RT addresses with one sub-address (30*668) microseconds. **Note:** If only 2 channels are available, BC-RT data transmission test alone can be done (MT operations will be discarded). |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
