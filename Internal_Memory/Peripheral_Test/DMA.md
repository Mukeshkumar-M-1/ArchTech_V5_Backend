# DMA Test Specification

| Test cases | Description |
|---|---|
| **DMA Test** | Verifies the time taken to transfer data between PCI and SDRAM, PCI to PCI, and SDRAM to SDRAM using the DMA controller. For each mode of data transfer, DMA channel number, source address, destination address, and size of data shall be configured. Data shall be transferred and verified at the destination. If transferred data matches the source data within acceptable time limits, test is PASS, otherwise FAIL. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
