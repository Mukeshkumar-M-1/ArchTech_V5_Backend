# Rocket IO Test Specification

| Test cases | Description |
|---|---|
| **Rocket IO Test** | Transmits, receives, and verifies bulk data based on the data rate required by application requirement. Counter data shall be written in the Tx channel and the same shall be read back in the Rx channel. If both data are the same, test is PASS, otherwise FAIL. Data transfer rate shall be calculated. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
