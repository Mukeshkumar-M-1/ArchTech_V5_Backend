# Counter Test Specification

| Test cases | Description |
|---|---|
| **Counter Test** | Carried out by enabling and then disabling counter interrupt after a defined time duration (60 seconds). If the interrupt counter value after disabling and the expected count value are the same, test is PASS, otherwise FAIL. **Note:** The test result with tolerance of +/-1 count in addition to the expected interrupt count will be considered as PASS. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
