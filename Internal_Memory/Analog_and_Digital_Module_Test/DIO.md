# DIO Test Specification

| Test cases | Description |
|---|---|
| **DIO Test** | Validates Digital Input channels and Digital Output channels considered that DI and DO channels are connected directly. Walking ones test shall be carried out for 'n' number of DI-DO pair channels (Test Patterns for 3-bit IO check: 000, 001, 010, 100, 111). Walking zeros test shall be carried out for 'n' number of DI-DO pair channels (Test Patterns for 3-bit IO check: 111, 110, 101, 011, 000). If the written pattern on DO channels and read pattern on DI channels are the same, test is PASS, otherwise FAIL. |

> **Note:** Descriptions may be modified as per the specific requirement criteria.
